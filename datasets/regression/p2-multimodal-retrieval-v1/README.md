# P2.3 Multimodal Retrieval Benchmark v1

该数据集用于验证多模态 RAG 检索流水线（P2.1 图片 Embedding/索引、P2.2 跨模态检索与 RRF 融合）在真实学术论文图表场景下的检索能力与冻结准入阈值。

## 数据集构成
- **论文覆盖**：10 份真实 AI Agent 论文（涵盖工作流编排、自我反思、多智能体环境、安全评估、博弈策略、数据 Agent 漏洞、记忆适应、深度研究、浏览器智能体等）。
- **正例查询 (30 例)**：覆盖系统架构图、算法流程图、基准对比柱状/折线图、安全风险分类法分类图、热力图、网格布局图等 6 种图表形态。所有正例均绑定真实 PDF 抽取的 `asset_id`、`document_id`、`page`、`bbox` 与 `caption`。
- **负例查询 (10 例)**：明确超出学术图表库范畴的负例（冷冻电镜、威尼斯历史账本、深海宏基因组、量子硬件等），测试检索系统的无答案拒答与误召回抑制能力。

## 准入冻结阈值
- `image Recall@5 >= 0.80`
- `MRR >= 0.60`
- `Artifact/Page/BBox 定位正确率 100%`
- `Citation/Evidence Closure 100%`
- `无答案误召回率 <= 0.10`
- `Text-only 回归零退化 100% PASSED`
