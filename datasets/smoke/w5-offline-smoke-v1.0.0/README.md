# W5 offline smoke fixture

This versioned fixture is a deterministic local-only product smoke input. It exercises
the packaged `conflux-weave offline-smoke` command through a paper-discovery-shaped
Task, SQLite Run, registered Delivery Artifact, Citation/Evidence closure and packaged
Workbench asset checks.

It contains no Provider response, public-source response, API key or private corpus.
The fixture is not evidence of live research capability and must not be used as a
quality benchmark. Semantic changes require a new fixture version.
