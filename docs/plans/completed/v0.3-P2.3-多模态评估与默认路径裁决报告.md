## 4. 准入阈值机械校验分析

1. **image Recall@5 (0.900 >= 0.80)**：
   - 采用线上真机 `jina-clip-v2` 跨模态特征与 BM25 融合检索，30 个正例学术图表检索中准确命中 27 个（25 个首位命中，2 个前五命中），Recall@5 达到 **90.0%**，显著超越 0.80 的冻结门槛。
2. **MRR (0.867 >= 0.60)**：
   - 目标图表在绝大多数正例中均作为首位命中返回，平均倒数排名达到 **0.867**，大幅优于 0.60 的基准。
3. **定位正确率 (100% == 100%)**：
   - 召回的每一个图片资产，其 `artifact_ref` 均指向有效的 `artifact-sha256-...` 物理文件，页码完全吻合，`bbox` 与 PDF 原始抽样位置绝对一致（误差 <= 2.0 pt）。
4. **Citation / Evidence Closure (100% == 100%)**：
   - 所有召回结果均具备完整的父 Chunk lineage、页码定位与缩略图 Artifact，能无缝转化为标准 `EvidencePayload` 并在报告写作阶段生成合规图片引用。
5. **无答案误召回率 (0.00 <= 0.10)**：
   - 在 10 个领域外负例查询中，因图文相似度得分远低于设定的相关性阈值（负例最高余弦 0.3431 < 正例最低余弦 0.3578），系统全部准确判定为“无答案”，误召回率为 **0.00**，远优于 <= 0.10 阈值。
6. **现有文本回归零退化**：
   - 全工程 525+ 测试用例全部保持 100% PASSED，多模态特性的引入未造成纯文本 RAG 与研究工作流的任何退化。

## 5. 默认路径裁决结论 (Adjudication Decision)

综合考虑 **检索质量**、**Provider 调用成本**、**延迟** 与 **鲁棒性**，裁决如下：

### 裁决 1：安全默认原则 (Safe Default)
- **生产默认状态**：当系统环境变量 `CONFLUX_WEAVE_MULTIMODAL_ENABLED` 为 `false`（默认）或未配置 `image_embedding_model` 时，生产启动链保持纯文本链路运行。
- **依据**：纯文本路径具有零额外 Provider 调用费用、零网络时延增加与 100% 的现有工程稳定性。

### 裁决 2：零成本图片检索降级 (Zero-Cost Caption Fallback)
- **降级机制**：在知识库中导入了富图片 PDF 但用户未配置视觉向量模型（或图片 Embedding 服务网络不可用）时，系统自动启用 **`caption_baseline`** 检索。
- **依据**：`caption_baseline` 在本基准上取得了 **Recall@5 = 86.7%**、**MRR = 0.850** 的优异成绩，且无需调用外部多模态视觉 Embedding API，既保障了基本图表检索体验，又杜绝了额外 Token 与网络开销。

### 裁决 3：全功能多模态路径 (Joint Multimodal Production Path)
- **激活条件**：显式配置 `CONFLUX_WEAVE_MULTIMODAL_ENABLED=true` 且指定 `image_embedding_model`。
- **执行策略**：启动 `MultimodalRetrievalPipeline`，通过图片向量索引与文本块向量索引并行检索，经 `multimodal_reciprocal_rank_fusion` 进行倒数排序融合。
- **异常容灾**：当视觉模型接口发生网络故障或超时时，自动生成 `conflux-weave.image-embedding.v1.failure` 故障 Artifact 并平滑回退至 Caption 检索，确保前台研究任务绝不中断。
