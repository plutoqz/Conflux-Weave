# Conflux-Weave v0.3 资料库工作台功能计划

## 1. 产品定位

资料库是论文、PDF、Markdown 和后续知识库使用的统一入口。
“文档库”和“知识库”不拆成两个页面：资料先进入资料库，再由用户决定是否加入当前知识库。
论文获取的结果默认作为资料入库，不默认生成研究报告。

## 2. 工作台入口

顶栏新增“资料库”分区，负责资料浏览、论文获取、资料处理、知识库状态和引用回溯。
研究页保留研究任务入口，但不再承担论文获取的主要入口职责。

## 3. 阶段一：资料库首页与资料总览

### 3.1 资料列表

展示全部已登记资料：

- 本地 PDF；
- 本地 Markdown；
- 通过论文获取保存的论文；
- 已解析资料；
- 已加入知识库资料；
- 处理失败或等待处理资料。

每条资料展示标题、来源、类型、添加时间、处理状态、是否入库和内容规模。

### 3.2 筛选、排序和搜索

支持按资料类型、来源、处理状态、入库状态筛选，按添加时间和最近使用时间排序，
并按标题、作者、文件名、标签和正文内容搜索。

### 3.3 添加资料

资料库提供统一的添加入口，支持上传 PDF、上传 Markdown，以及把已获取论文保存进资料库。
添加相同资料时提示已存在，不静默创建重复记录。

### 3.4 资料详情

资料详情展示来源信息、版本、文件信息、解析状态、知识库状态和处理记录。
用户可以预览 PDF 页面、解析后的 Markdown、目录和可定位正文片段。

### 3.5 阶段一验收

- 用户可以从资料库看到现有资料和准确状态；
- 用户可以添加 PDF、Markdown 和论文获取结果；
- 用户可以打开资料详情并查看内容；
- 重复资料有明确提示；
- 失败资料显示原因和下一步动作；
- 桌面端和移动端不出现横向溢出；
- 不影响现有对话、研究、引用和设置页面。

## 4. 阶段二：论文获取入库

状态：`implemented_pending_live_source_check`（资料库入口、搜索、获取和入库流程已接入；尚未执行真实 arXiv 下载验收）。

### 4.1 论文搜索

在资料库中提供论文搜索入口，支持输入主题、检索问题和候选数量，展示标题、作者、摘要、年份和来源。

### 4.2 论文操作

每个候选结果支持查看、获取、重新获取、加入资料库和查看已有版本。
获取成功后默认停留在资料库，不生成研究报告。

### 4.3 论文处理状态

显示等待、获取中、成功、已存在、全文不可用、下载失败和解析失败等状态，并提供对应恢复动作。

## 5. 阶段三：知识库使用状态

资料详情中明确区分“已登记到资料库”和“已加入当前知识库”。

用户可以单个或批量加入知识库、移除资料、重新处理资料，并查看当前知识库资料数量、
待处理数量、失败数量、最近更新时间和是否可以用于问答。

## 6. 阶段四：对话与研究联动

### 6.1 知识库问答

知识库问答默认使用当前有效知识库，回答引用可以跳转到资料详情、页面或正文片段。

### 6.2 深度研究

深度研究默认使用“网络 + 当前知识库”的混合模式，不提供“本地资料 / 网络 / 混合”选择器。
研究结果中显示实际使用的资料范围，并区分本地资料证据和网络来源。

### 6.3 论文联动

资料库中的论文可以执行“基于此资料开始研究”；论文获取成功后也可以加入知识库，再进行知识库问答。
论文获取本身不自动创建对话或研究 Run。

## 7. 阶段五：引用、版本与恢复

- 引用可以回到资料、版本、页面和原始片段；
- 历史研究继续保留原资料版本；
- 新版本不静默覆盖旧版本；
- 资料处理、入库和更新失败时提供重试、查看原因、继续使用旧版本等动作；
- 资料详情展示被哪些回答和研究使用过。

## 8. P2.0 多模态后续

资料库闭环稳定后，再加入图片预览、图片引用、图片与正文关系和跨模态检索。
图片能力沿用同一资料库，不新增独立图片库。

## 9. 明确不做

- 不把论文获取默认变成研究报告；
- 不在深度研究中增加资料范围选择器；
- 不单独建立文档库和知识库两个入口；
- 不先做 Memory、Skill/MCP、项目管理或前端框架迁移；
- 不用假资料填充尚未实现的页面。

## 10. 执行顺序

1. 阶段一：资料库首页、列表、添加入口和资料详情；
2. 阶段二：论文搜索、获取和入库；
3. 阶段三：知识库状态、批量处理和可用性提示；
4. 阶段四：对话引用回溯和论文到研究联动；
5. 阶段五：版本、恢复和使用记录；
6. P2.0：图片资产和多模态能力。
