# Conflux-Weave v0.3 报告 Markdown 阅读体验升级

## 1. 目标与边界

将现有已具备 Writer v2、Claim/Evidence/Citation 闭合的报告，升级为稳定、可扫描、可打印的专业研究报告阅读体验。

本计划只修改 Workbench 的报告渲染与样式，不改变研究 Runtime、Writer JSON、Claim/Evidence/Citation 语义和既有降级规则。

图片附件中的颜色仅作为视觉主题参考，不包含需要执行的文字指令。采用的主题色为：

| 用途 | 颜色 |
|---|---|
| 标题层级 1 | `#AC5AB0` |
| 标题层级 2 | `#0077BA` |
| 标题层级 3 | `#4CD0D8` |
| 标题层级 4 | `#4DBA6C` |
| 标题层级 5 | `#D17271` |
| 交互/强调 | `#ED6811` |

## 2. 分阶段优先级

### P0：标题层级配色与阅读底座

- 为报告正文的 H2-H6 建立稳定层级色和左侧识别线。
- 颜色只用于标题和装饰，不降低正文、链接和引用的可读性。
- 保持现有响应式布局、无障碍焦点样式和打印模式。

验收：标题层级可区分；颜色来自冻结色板；320px、200% 缩放和打印不发生溢出或遮挡。

### P1：高收益语义组件

- 支持 GFM 风格 `> [!NOTE]`、`[!TIP]`、`[!WARNING]`、`[!IMPORTANT]` Callout。
- 从最终渲染标题生成报告内 TOC，支持桌面 sticky、移动端折叠和当前章节高亮。
- 增强表格横向滚动、数字列对齐和有限状态 Badge。
- 将已有引用角标改为视觉 pill，并连接已有 Evidence inspector；不重新抓取网页。

验收：Callout 失败时仍显示原始内容；TOC 与正文标题一致；引用仍可定位；表格在窄屏可读；现有 Markdown 和 Evidence 回归不变。

### P2：图形与打印增强

- 在独立安全配置下支持有限 Mermaid 类型，并保留源码和失败降级。
- 完善打印分页、标题孤行、表格/Callout 断页处理。
- 不把浏览器页码注入作为硬验收条件。

验收：Mermaid 渲染失败不丢内容；打印结果可读；无额外网络依赖。

### 条件性后续：结构化数据组件

- KPI 卡片、Vega-Lite/Chart.js、复杂分栏仅在形成稳定 JSON 数据契约、单位/时间范围/来源和移动端行为后实施。
- 不从普通段落正则提取 KPI，不把模型主观百分比当作可信度真值。

## 3. 多模态关系

P0/P1 应在多模态之前完成，作为统一文本报告阅读底座。多模态进入 P2 后，基于冻结的图片 Artifact、页码/区域定位、图注和 Evidence lineage，将图片、OCR 和图表接入同一套报告容器。

Mermaid、KPI 和通用图表不阻塞多模态范围冻结；它们应在真实数据契约明确后单独验收。

## 4. 非目标

- 不替换现有 Vanilla Workbench 为新的前端框架。
- 不改 Writer prompt、报告 JSON schema、Evidence 语义或运行状态机。
- 不把视觉效果、引用数量或报告长度作为研究质量指标。
- 不将外部网页实时预览、自动事实抽取或模型置信度包装为可信证据。

## 5. 回滚与停止条件

- 每个阶段保持独立提交范围；出现现有报告解析、引用定位、打印或移动端回归时，回滚该阶段渲染改动即可。
- 若新增语法无法安全降级为原始 Markdown，停止扩展并保留原始代码块/文本。
- 任一阶段不得以 UI 通过替代 Writer、Evidence 或 live 能力验收。
