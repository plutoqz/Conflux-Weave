## 0. 诊断与设计动机

### 0.1 为什么当前美化“有效果，但仍达不到专业水准”？
经对比 Linear、Raycast、Cursor 等顶级开发者/AI 工具与当前工作台界面，我们发现当前界面存在以下 4 大本质差距：

1. **整体风格（Visual Depth & Polish）缺乏“精密仪器感”**：
   - 现有页面仍带有较多“常规 Web 页面”的扁平感与大块白/灰色块拼凑感，缺乏顶级产品特有的**三层标高深度体系（Layered Elevation）**、**1px 发丝级微描边（Hairline Inset Borders）**与**微型内嵌高光（Inset Highlights）**。
   - 暗黑模式虽然使用了深色，但缺乏像 Raycast 那样深邃但透气、微蓝移的宇宙黑曜石质感（`#08090c` / `#0f1117`），光晕与阴影阶梯未形成有机整体。

2. **侧边目录（Sidebar & TOC）信息架构与层级粗糙**：
   - **左侧历史栏**：仅仅是纯文字列表简单堆叠，缺乏状态指示灯、两行信息层级、耗时/证据量元数据标签，无法一眼扫清任务状态；且不支持折叠为轻量图标轨（无法进入免打扰的“Zen 专注阅读模式”）。
   - **右侧目录（TOC）**：目前目录排布平淡，缺乏类似 GitBook / Stripe Docs 的**树状导航轨**（纵向导向线 + 滚动监听高亮块 + 阅读进度条），层级间距不明确。

3. **布局安排（Layout Architecture）产生横向挤压与阅读疲劳**：
   - 在研究成果页面，当前常常同时呈现“侧栏 + 目录 + 正文 + 证据检查器”4 列并列，在主流 1440x900 或 1080p 笔记本屏幕上，核心长篇学术报告被严重挤压至不足 600px，阅读舒适度断崖式下跌。
   - 缺乏现代“**自适应三栏演播室架构（Adaptive Studio Tri-Pane）**”：未将核心研读区独立为 760px~920px 黄金阅读宽度，证据检查与元数据未能以平滑抽屉/上下文面板的形式弹性呈现。

4. **按钮与交互控件（Buttons & Controls）触感单一**：
   - 现行按钮为常规的纯色圆角矩形，缺乏微投影层级（Elevation）、顶部微发光边缘（Top Inset Bevel）、微动效按压反馈（Press Micro-scale）以及快捷键提示标牌。
   - 交互反馈停留在粗放的背景色变化，未建立系统的“主操作（Primary）、次级微边框（Secondary）、透明幽灵（Ghost）、分段胶囊（Segmented Pill）”四大控件家族。

## 2. 细化设计方案

### 2.1 整体风格重塑：Precision Studio（精密工作室）体系

#### 2.1.1 表面深度标高系统（Surface Elevation System）
放弃单一的背景色，建立物理级的层次堆叠：
- **Level 0 (Canvas 底层)**：
  - 浅色：`#f8f9fc`（极微蓝冷灰，比纯白更抗疲劳）
  - 深色：`#08090d`（深度宇宙黑曜石，避免纯黑 OLED 拖影）
- **Level 1 (Panels 侧栏与面板)**：
  - 浅色：`#f1f3f7`，边框 `rgba(0, 0, 0, 0.06)`
  - 深色：`#0f1117`，边框 `rgba(255, 255, 255, 0.08)`
- **Level 2 (Cards 卡片与正文舞台)**：
  - 浅色：`#ffffff`，微阴影 `0 1px 3px rgba(0,0,0,0.04), 0 1px 2px rgba(0,0,0,0.02)`，顶边微高光 `inset 0 1px 0 rgba(255,255,255,0.9)`
  - 深色：`#141721`，微阴影 `0 4px 12px rgba(0,0,0,0.3)`，顶边微高光 `inset 0 1px 0 rgba(255,255,255,0.07)`
- **Level 3 (Overlays 浮动工具栏与下拉舱)**：
  - 采用半透明毛玻璃：`backdrop-filter: blur(16px) saturate(180%)`，浅色 `rgba(255, 255, 255, 0.82)`，深色 `rgba(17, 21, 30, 0.82)`。

#### 2.1.2 字体排版与微字偶间距（Micro-Typography）
- **字偶微调（Letter-spacing）**：
  - 报告大标题（H1/H2）：`letter-spacing: -0.02em`，强化凝聚感与力量感。
  - 正文（Body）：`line-height: 1.75; letter-spacing: 0; margin-bottom: 1.1em;`。
  - 元数据/代码/标签：`letter-spacing: 0.02em; font-feature-settings: "tnum" 1;`（等宽数字，时间与数值不再因数字宽度变动而晃动）。

### 2.2 侧边目录与导航重构：Linear-Style Rail & Tree TOC

#### 2.2.1 左侧历史导轨（Runs Sidebar）升级
- **顶栏检索与筛选（Quick Filter Header）**：
  - 新增极简搜索框：即时按关键词检索历史会话与研究成果。
  - 状态筛选胶囊：`[ 全部 ]` · `[ 已完成 ]` · `[ 进行中 ]`，点击快速收敛列表。
- **项目卡片（Run Card Item）三层精细排版**：
  - **行 1**：状态呼吸灯（完成为微绿发光环，执行中为翡翠雷达转动，等待为琥珀点） + 成果主标题（超长单行优雅截断 `text-overflow: ellipsis`，加粗清晰）。
  - **行 2**：任务摘要短语或核心问题（淡灰次级字体，2行截断）。
  - **行 3**：微型元数据信息（相对时间如 `10分钟前` · 证据量标签如 `5 引用` · 模式标签 `深度研究`）。
- **激活态（Active State）高级处理**：
  - 废弃生硬的整块变色，改用 Linear 经典激活标杆：
    - 卡片左侧浮现 2.5px 翡翠微霓虹光条（`border-left: 2.5px solid var(--accent);`）；
    - 卡片背景施加微透光层（`color-mix(in srgb, var(--accent) 8%, var(--surface-card))`）；
    - 右侧显示微型激活箭头或高亮指示器。
- **Zen Focus Mode（专注阅读模式一键折叠）**：
  - 侧栏顶部增加折叠触发键（`[` 图标），支持一键将侧栏收缩为 **48px 极简图标轨**（仅保留状态圆点与序号悬浮提示），为中间长篇正文释放出 220px 的宝贵水平视野！

#### 2.2.2 右侧目录（Table of Contents）升级为 GitBook 级树状导向轨
- **纵向贯通导轨（Vertical Guide Rail）**：
  - 目录左侧设置一条 `1.5px` 浅灰贯通线（`border-left: 1.5px solid var(--border-subtle)`）。
- **滚动监听游标（Active Scrollspy Marker）**：
  - 当前浏览章节的指示器会像一粒翡翠药丸，沿着导向线平滑移动，精准对应当前视口所在章节。
- **树状多级缩进**：
  - H1、H2、H3 具有清晰的阶梯缩进（`12px / 24px`），H1 字体略大并带点阵，H2/H3 紧凑内收。
- **顶部阅读进度条**：
  - 目录顶栏增加当前文章阅读百分比显示（如 `● 阅读进度 42%`）与微型水平进度条。

### 2.3 布局安排重构：自适应三栏演播室架构（Adaptive Studio Tri-Pane）

彻底根治 4 列挤压问题的根本布局方案：

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ Topbar: [CW Monogram] [总览] [对话] [研究] [资料库] [设置]        [深浅切换] [●就绪] │
├────────────────┬─────────────────────────────────────────────┬────────────────┤
│ 侧边栏 (Rail)  │ 黄金研读中台 (Golden Document Stage)        │ 上下文面板     │
│                │                                             │ (Context Pane) │
│ [ 搜索历史.. ] │ ┌─────────────────────────────────────────┐ │                │
│ [全部/完成/进行]│ │ 浮动文档操作条 (Sticky Document Toolbar) │ │ [ 目录 (TOC) ] │
│                │ │ 面包屑 · 阅读 6min · [复制] [下载] [全屏] │ │ [ 引用证据(5)] │
│ 1. 空间知识图谱│ └─────────────────────────────────────────┘ │ [ 运行指标 ]   │
│   ● 5引用 · 1h │                                             │                │
│                │ # 标题 1                                    │ ├──────────────┤
│ 2. GIS智能体.. │ 正文宽度严格控制在 760px ~ 900px 黄金范围   │ │ 树状目录轨   │
│   ● 8引用 · 2h │ 字符密度保持 65~75 字/行，最佳学术沉浸体验  │ │ 或证据抽屉   │
│                │                                             │ │ (无缝 Tab切) │
│ [收起 ◀]       │ 代码块一键复制 · 表格现代斑马纹 · 引用药丸   │ │              │
└────────────────┴─────────────────────────────────────────────┴────────────────┘
```

#### 关键布局特征：
1. **黄金研读中台（760px ~ 920px）居中保全**：
   - 无论用户屏幕多大或多小，核心 Markdown 报告的正文宽度始终被锁在人眼最舒适的阅读区间（避免行宽过长导致重读，避免行宽过窄导致高频换行）。
2. **浮动文档操作条（Sticky Document Toolbar）**：
   - 在长篇正文上方常驻毛玻璃工具条：包含路径面包屑（如 `研究成果 / 2026-09-07 / 空间知识图谱`）、全文阅读用时估算、一键全屏专注模式、一键复制全文 Markdown、一键下载为 `.md` 文件。
3. **右侧面板“智能双模态（TOC 目录 ↔ Evidence 证据抽屉）”**：
   - 将目录与证据检查器融为一体，采用双 Tab 切换（`[ 目录树 ]` / `[ 事实证据 (4) ]`）。
   - 用户在正文中点击任何 `[1]`、`[2]` 引用药丸时，右侧面板**以 150ms 丝滑滑动切换至该条证据的卡片**，并对该证据卡片施加翡翠黄光晕脉冲；**绝不额外挤出第 4 列破坏中间布局**！

### 2.4 按钮与交互控件重构：Precision Control System（精密控件体系）

#### 2.4.1 主操作按钮（Primary Button）
- **材质与层次**：
  - 背景采用多层线性渐变：
    - 浅色：`linear-gradient(180deg, #10b981 0%, #059669 100%)`
    - 深色：`linear-gradient(180deg, #10b981 0%, #047857 100%)`
  - 顶部微发光斜角：`box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.3), 0 1px 3px rgba(0, 0, 0, 0.12), 0 4px 10px rgba(16, 185, 129, 0.2);`
  - 边框：`1px solid rgba(0, 0, 0, 0.15)`
- **动效微反馈**：
  - Hover：上浮 1px，投影与光晕轻微扩展；
  - Active/Press：下沉 1px，微缩放 `transform: scale(0.98)`，内阴影增加，带来真实的物理按键机械手感。
  - 内置快捷键标志（如 `发送 ↵`）。

#### 2.4.2 次级与幽灵按钮（Secondary & Ghost Button）
- **次级按钮（Secondary）**：
  - 浅色：纯白底色 + `1px solid #e2e8f0` + 微投影 `0 1px 2px rgba(0,0,0,0.05)`；
  - 深色：`rgba(255, 255, 255, 0.05)` 半透明底色 + `1px solid rgba(255, 255, 255, 0.1)` + 顶边微高光；
  - Hover：边框提亮至品牌主色，文本轻微提亮。
- **幽灵按钮（Ghost）**：
  - 平时不显山露水，Hover 时浮现柔和背景色（浅色 `#f1f5f9`，深色 `rgba(255, 255, 255, 0.08)`），用于辅助图标按钮（如复制代码、主题切换、全屏切换）。

#### 2.4.3 分段胶囊选择器（Segmented Pill Controls）
- 顶栏 Tab 导航与 Chat 问答模式选择器升级为 macOS Sequoia / Raycast 级滑动胶囊：
  - 外框为一个精致的微凹凹槽容器（`background: var(--surface-subtle); border-radius: 9999px; padding: 3px;`）；
  - 激活项为独立悬浮白卡片（深色为深色浮动卡片），配备微投影与平滑弹性位移动画。

#### 2.4.4 对话悬浮输入舱（Floating Composer Capsule）
- 输入框不再是贴底长框，而是离底 24px 的现代大圆角悬浮舱：
  - 具备全玻璃拟态磨砂底板（`backdrop-filter: blur(20px)`）；
  - 聚焦时光晕扩散：`box-shadow: 0 0 0 2px var(--accent), 0 12px 32px -4px rgba(16, 185, 129, 0.15)`；
  - 集成模式快捷切换（`直接问答` / `知识库` / `深度研究`）与快捷键徽章（`⌘ + ↵ 发送`）。

## 3. 技术落地可行性与红线保障

### 3.1 严格遵守既有约束
1. **100% 零外部 CDN（Zero External Dependencies）**：
   - 所有图标采用内联微型 SVG 或纯 CSS 绘制（不拉取任何外部网络字体或第三方 CDN 链接）；
   - 所有字体使用高质量系统预置字体栈（`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Inter", sans-serif` 与 `"JetBrains Mono", Consolas, monospace`）；
   - 严格保证源码内无任何字面量 `"http://"` 或 `"https://"`。
2. **纯原生 Vanilla ESM，无需打包**：
   - 所有动效均通过 CSS Custom Properties、Transitions 与原生原生 JavaScript 事件实现，零编译、零构建依赖，由 FastAPI 单一进程直接服务。
3. **保护既有测试用例与契约**：
   - 严格保留 `tests/test_workbench.py` 断言的所有 DOM ID（`#answer-content`、`#runs-list`、`#toc`、`#evidence-inspector` 等）与关键 CSS 类名与媒体查询。
