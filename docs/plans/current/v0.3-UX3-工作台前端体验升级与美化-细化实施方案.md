## 0. 方案背景与目标

### 0.1 现状诊断
Conflux-Weave 目前已成功构建基于 FastAPI + SQLite + LanceDB + Artifact Store 的个人研究智能工作台，前端采用原生 Vanilla HTML/CSS/ES Modules，具备极高的稳定度、可恢复性与零网络外部依赖。

但在日常实际使用中，当前前端存在以下明显体验与视觉短板：
1. **色调陈旧与视觉单一**：现行“苔原 Moss”配色偏暗沉，且报告彩虹色标题与工作台主色割裂；缺乏深浅主题切换（无 Dark Mode）。
2. **排版格式落后**：正文段落强制首行缩进 2 字符（`text-indent: 2em`），在包含代码块、列表、表格和英文技术综述的科研报告中显得极不协调；代码块缺少一键复制与语法高亮。
3. **空间利用与视线挤压**：研究视图在桌面端经常同时出现侧栏 + 目录轨 + 正文 + 证据检查器 4 列，正文阅读宽度受限；总览页与设置页空间利用率低。
4. **交互质感不足**：对话气泡偏老式直角卡片、三模式弹出菜单操作生硬、数据指标全为纯文本展示、模态框与骨架屏缺乏现代丝滑平滑过渡。

### 0.2 优化目标
在**完全不改变后端 API、数据库 Schema、Runtime 状态语义，且严格遵守同源零外部 CDN 限制**的前提下，对前端界面进行一次全方位的“现代学术/工程级”交互体验与视觉美化升级，使之具备类似 Claude / GitBook / Linear 水平的高级质感与专注科研阅读体验。

## 1. 约束与非目标（Non-Goals）

### 1.1 必须坚守的硬性约束
1. **绝对同源与零外链（Zero-CDN）**：
   - 不得在 HTML、CSS、JS 源码中引入 `http://` 或 `https://` 外链资源（`test_workbench.py` 严格校验此项）。
   - 字体、样式、脚本、图标全量本地化交付。
2. **零前端打包链（No Build Step）**：
   - 保持原生 Vanilla HTML5 + CSS3 + ES Module 模式，无需 npm / webpack / vite 构建环境，继续由 FastAPI 单一进程直接托管。
3. **保护现有测试契约与 DOM 结构**：
   - 保留 `test_workbench.py` 所依赖的所有 DOM ID、样式类名、data 属性与事件逻辑。
4. **全端自适应与无障碍**：
   - 维持 `1440x900`、`1024x768`、`768x1024`、`390x844`、`320x568` 五大视口以及 200% 缩放下的零水平溢出。

### 1.2 非目标
- 不重构或替换后端接口与 SSE 事件协议。
- 不引入重型前端框架（React/Vue/Svelte）。
- 不涉及 P2 阶段的 PDF 多模态图像向量提取后端逻辑。

## 2. 细化设计方案

### 2.1 设计系统（Design System）与主题体系

#### 2.1.1 双主题色彩规范（Light & Dark Mode）
建立以纯 CSS Custom Properties 为核心的语义化调色盘，支持一键切换与跟随系统（`prefers-color-scheme`）：

- **浅色主题（Light Mode · 经典纸质学术）**：
  - 界面基底：`--bg-canvas: #f9f9fb`（柔和低饱和灰白，摆脱老旧偏黄感）
  - 表面层/卡片：`--bg-surface: #ffffff`
  - 侧栏/次级底色：`--bg-subtle: #f3f4f7`
  - 主文字色：`--text-main: #111827`（深碳素色，提高可读对比度）
  - 次级文字色：`--text-muted: #6b7280`
  - 品牌强调色：`--accent: #15803d`（现代深翡翠绿，保留科研沉稳基调）
  - 边框微描边：`--border-hairline: #e5e7eb`、`--border-focus: #15803d`
- **深色主题（Dark Mode · 沉浸深空工程）**：
  - 界面基底：`--bg-canvas: #0f1217`（深黑灰，避免高对比纯黑疲劳）
  - 表面层/卡片：`--bg-surface: #181d24`
  - 侧栏/次级底色：`--bg-subtle: #13171d`
  - 主文字色：`--text-main: #f3f4f6`
  - 次级文字色：`--text-muted: #9ca3af`
  - 品牌强调色：`--accent: #22c55e`（明亮翠绿）
  - 边框微描边：`--border-hairline: #262e38`

#### 2.1.2 字体与排版阶梯（Typography Hierarchy）
- **字体栈**：优先系统现代无衬线（Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif）；代码栈采用等宽字体（"Cascadia Code", "Fira Code", Consolas, monospace）。
- **取消硬缩进**：彻底剔除 `.answer-body p` 的 `text-indent: 2em`。改用国际通用的段落间隙 `margin-block: 0.85em` 与舒适行高 `line-height: 1.75`。
- **报告标题统一性**：淘汰突兀的彩虹色彩条，采用同色系阶梯灰度 + 品牌色左强调线，使长篇学术报告具备正式出版物级排版质感。

#### 2.1.3 微质感与空间规范
- **微阴影层级（Elevation Shadows）**：
  - Card: `0 1px 3px rgba(0, 0, 0, 0.05), 0 1px 2px rgba(0, 0, 0, 0.03)`
  - Hover: `0 10px 25px -5px rgba(0, 0, 0, 0.08), 0 8px 10px -6px rgba(0, 0, 0, 0.04)`
  - Modal/Popover: `0 20px 40px -15px rgba(0, 0, 0, 0.2)`
- **圆角规范**：Sm (4px), Md (8px), Lg (12px), Pill (9999px)。
- **动效微交互**：按钮与卡片增加 `transition: all 160ms cubic-bezier(0.16, 1, 0.3, 1)`；骨架屏升级为斜向 Shimmer 现代流光扫光。

### 2.2 核心模块界面重构设计

#### 2.2.1 顶栏（Topbar）
- **品牌区域升级**：升级为圆角微质感徽标，结合轻量精致排版。
- **导航指示优化**：Tab 从生硬的下划线升级为胶囊平滑高亮块（Sliding/Active Pill），悬浮带有微动效。
- **右侧功能区**：
  - 健康度指示升级为状态胶囊（带有脉冲呼吸点和悬停状态说明）。
  - 新增 **深/浅色模式切换按钮**（内联本地 Sun / Moon 矢量图标），状态持久化至 `localStorage`。

#### 2.2.2 总览工作台（Overview Dashboard）
- **从简陋列表变为聚合控制台**：
  - **Hero 欢迎区**：卡片化布局，集成“快速提问”、“新建研究”与“导入论文”三大核心捷径。
  - **系统健康度网格**：将原先简单的文本列表升级为 3 块具有阴影与状态色标的精致监控卡（运行数据库、工件库、模型服务），直观显示就绪状态、响应时延与指引。
  - **近期研究速览**：采用时间线/卡片流，直观展示研究标题、生成时间、模式 Tag 与完成度徽章。

#### 2.2.3 统一对话工作台（Chat Workbench）
- **气泡排版升级**：
  - 用户消息：右上对齐的现代胶囊卡片，深色微强调底色，圆润边角。
  - Agent 回复：全宽开放式排版，区分直接问答、知识库片段与深度研究完整报告；深度研究任务提供进度步进折叠条。
- **输入控制区（Composer）重构**：
  - 模式切换：将生硬的向上弹出列表重构为轻巧的模式切换 Pill 栏（直接问答 / 知识库 / 深度研究），带有简洁图标与即时特性提示。
  - 输入框强化：圆角大输入框，提升打字舒适度，右下角整合快捷键提示与发送按钮。
- **左侧会话历史**：增加高亮激活态与悬停删除/重命名交互挂钩，清晰显示会话模式图标与消息计数。

#### 2.2.4 研究工作台（Research Workbench）
- **四列拥挤问题重塑**：
  - **TOC 目录轨**：改造成半透明浮动悬吸式侧轨，可一键展开/收起，默认不强占主正文栅格宽度。
  - **Evidence 检查器（Inspector）**：桌面端优化为平滑滑出的右侧抽屉（Drawer），带有独立的卡片式元数据与原文字段高亮。
- **运行指标摘要带（Summary Strip）**：
  - 将 4 个干燥的文本框升级为现代仪表盘卡片（微型环形/条形进度、Token 用量芯片、检索轮次与花费提示）。
- **富文本交付物（Markdown Report）渲染增强**：
  - 代码块新增语言标牌与“一键复制”悬浮交互。
  - 表格增加现代斑马纹交替与表头半透明吸顶。
  - 提示块（`[!NOTE]`, `[!TIP]`, `[!WARNING]`, `[!IMPORTANT]`）升级为现代左侧带 Icon 与对应语义色调的优雅微容器。
  - 引用标签 `[1]` 升级为高亮交互药丸，点击时平滑滚动至对应证据项或呼出抽屉。

#### 2.2.5 资料库工作台（Library Workbench）
- **顶栏统计聚合**：采用 6 块平铺现代微卡片，大字号呈现资产体量。
- **资料列表卡片化**：
  - 区分 PDF（红/橙色系角标）、Markdown（蓝/青色系角标）、网络论文（紫色系角标）。
  - 增加正文命中高亮片段的展示层次。
- **论文搜索发现面板**：
  - 优化筛选栏（年份、来源、OA 勾选项）的网格对齐。
  - 候选论文结果卡片重构：标题、作者、发表物、被引数（如果有）、摘要支持折叠展开，操作按钮视觉层级明确（主要按钮：获取全文；次要按钮：保存元数据）。

#### 2.2.6 设置与模型管理（Settings View）
- **表单体验升级**：
  - 分组卡片化（Model Provider / System Checks / Storage Locations / Budget）。
  - 快速预设助手：虽然配置由用户填写，但可提供常用 Base URL 与 Model 建议提示胶囊（如 Qwen/DashScope, DeepSeek, OpenAI, Ollama 本地服务等点击自动填充）。
  - 连接测试按钮：加入 Loading 旋转态与平滑出结果动画。

### 3.2 零外链代码高亮与复制技术方案
- **复制按钮**：在 `shared.js` 的代码块生成逻辑中注入浮动操作条，点击调用浏览器原生 `navigator.clipboard.writeText`，并呈现 1.5s 的打勾反馈。
- **轻量本地高亮**：通过极简的正则表达式规则（针对 Python, JS/TS, JSON, Markdown, Shell 等常见语言），对关键字、字符串、数字、注释进行纯前端分词并包裹轻量 span，完全不需要加载巨型外链库（如数十 KB 的 Prism/Highlight.js），保持零外链与零体积负担。

1. **自动化测试验收**：
   - `uv run --frozen pytest tests/test_workbench.py` 100% 通过。
   - `assert "http://" not in index + styles + script` 与 `assert "https://" not in index + styles + script` 严格通过。
   - 全部既有 DOM ID、测试用例无一报错。
2. **视觉与交互验收**：
   - 界面呈现出高水准现代学术/工程质感，支持深浅双主题自由切换。
   - 长篇研究报告排版整洁自然，代码块可一键复制，引用跳转顺畅。
   - 对话视图气泡层次分明，模式切换直观清晰。
   - 在 1440px、1024px、768px、390px 视口下均表现优秀，无横向滚动条或布局错乱。
