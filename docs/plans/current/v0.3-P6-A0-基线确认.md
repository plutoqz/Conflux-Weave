## 3. 数据结构要点（权威状态 = var/db + var/artifacts）

- SQLite 单库 `var/db/conflux-weave.sqlite3`（含 chat_messages/conversations）：tasks、runs(status: accepted/queued/running/waiting_for_user/cancelling/succeeded/partial/failed/cancelled/expired)、steps、artifacts(content_hash 寻址)、artifact_registrations、deliveries(disposition: complete/partial/no_answer + evidence_refs_json)、delivery_artifacts、attempts、leases、run_events、step_policies、attempt_effects、budget_limits/reservations/entries、errors、agent_messages/agent_events、memories、memory_candidates、skills、mcp_servers。
- 产物存储：`var/artifacts/sha256/<2位>/<hash>` 内容寻址；另有 `source-cache`。
- 报告产物：media_type `text/markdown`，schema 如 `conflux-weave.deep-research-report.v3`（W3.5 融合）、`conflux-weave.managed-research-report.v1`、`conflux-weave.verified-research-report.v2`、`conflux-weave.durable-research-report.v1`、`conflux-weave.research-report-document.v5`、`conflux-weave.document-report.v1`；配套 manifest schema（deep/managed/durable/verified-research-manifest）携带 sources（标题/URL/快照/hash/获取时间）、code_revision、limitations。
- Evidence：不在独立表，存于注册的 rank-checkpoint（`conflux-weave.w3.rank-checkpoint.v1`）或 durable-research-evidence 产物的 JSON 内；`delivery.evidence_refs` 持 ID；`GET /api/v1/evidence/{id}` 按 run 检索（quote/locator/extraction_method/modality）。
- RAG 问答（模式 B）：`chat_messages(mode='rag')` + `context_artifact_id`（`conflux-weave.chat-rag-context.v1`，含 snippets[index/chunk_id/score/snapshot/locator/text]、answer_checks、citations）。
- 笔记：`DocumentNote`（notes-registry.json + note 产物），自带 `render_markdown()`；节级 citations 指向文档 segment。
- 前端报告加载路径：`GET /runs/{id}` → `delivery.artifact_ids[0]` → `GET /runs/{id}/artifacts/{aid}/content`（`web/src/modules/research/ResearchView.tsx`）。
