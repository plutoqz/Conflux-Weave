## 1. 架构目标与技术指标

### 1.1 核心度量指标契约 (Service Level Indicators)

| 指标维度 | 现行轻量模式 (W3.2) | 阶段一重构目标 (Deep Research V2) | 测量与验证手段 |
|---|---|---|---|
| **时间预算容忍度** | 1~3 分钟超时敏感 | **15~20 分钟** 长程异步执行 | 进度心跳与可观测 SSE 阶段推进 |
| **参考来源规模** | 上限固定 10 篇 | **60~120 篇** 高权威异构源 | `SourceSnapshot` 去重台账审计 |
| **检索探索拓扑** | 单轮 1~2 个子问题检索 | **2~3 跳递归外链跟随 (Recursive Spanning)** | 探索图深度与外链追踪命中记录 |
| **反思与自省机制** | 无（检索到什么写什么） | **专职 Reviewer 审计证据缝隙与冲突并定向补捞** | 《证据空白与冲突消除备忘录》 |
| **最终产出篇幅** | 1,500~3,000 字摘要型研报 | **8,000~15,000 字深度学术级综述** | 字符统计与多章节结构完整性校验 |
| **格式与分析深度** | 纯文本段落与引用清单 | **技术演进谱系图 (Mermaid) + 全景对比矩阵表** | Markdown 结构化组件语法渲染校验 |
| **断点恢复韧性** | 仅外层批次粗粒度恢复 | **章节级（Section-level）细粒度热恢复** | 中途硬杀 Worker 重启无损继承测试 |

## 3. 数据模型契约设计 (Data Schemas)

新增独立模块包：`src/conflux_weave/long_horizon_research/`。

### 3.1 综述大纲与假设树 (`spec.py`)

```python
@dataclass(frozen=True)
class ResearchProbe:
    probe_id: str
    target_aspect: str          # 具体的论证切面（如 "FP8 相比 BF16 的精度损失与显存节约比率"）
    query_intent: str           # 检索意图与核心关键词
    expected_data_type: str     # "quantitative_metric" | "architectural_tradeoff" | "historical_milestone"

@dataclass(frozen=True)
class SurveyChapterPlan:
    chapter_id: str
    chapter_index: int
    title: str                  # 章节标题（如 "二、硬件友好型量化算法演进脉络"）
    core_thesis: str            # 本章核心立论假设
    probes: tuple[ResearchProbe, ...]
    depends_on: tuple[str, ...] # 逻辑依赖章节

@dataclass(frozen=True)
class ResearchOutlineTree:
    objective: str
    background_summary: str
    target_word_count_range: tuple[int, int]  # (8000, 15000)
    chapters: tuple[SurveyChapterPlan, ...]
    created_at: str
```

### 3.2 递归探索图与来源候选 (`search_graph.py`)

```python
@dataclass(frozen=True)
class DiscoveredSource:
    source_id: str
    url: str
    title: str
    snippet: str
    full_text: str
    authority_score: float      # 来源权威度打分 (0.0 ~ 1.0)
    hop_depth: int              # 递归深度 (0: 初始检索, 1: 首页外链, 2: 二级引用)
    parent_url: str | None
    extracted_outbound_links: tuple[str, ...]

@dataclass
class ExplorationGraphState:
    visited_urls: set[str]
    pending_queue: list[dict[str, Any]]
    collected_sources: list[DiscoveredSource]
    total_tokens_consumed: int
```

### 3.3 反思审计备忘录 (`reflection_auditor.py`)

```python
@dataclass(frozen=True)
class EvidenceGapFinding:
    chapter_id: str
    probe_id: str
    gap_description: str        # 缺失的数据或论据点
    remedy_query: str           # 拟执行的二次定向补捞 Query

@dataclass(frozen=True)
class ContradictionFinding:
    topic: str
    claims_a: str               # 来源 A 的主张
    source_a_ref: str
    claims_b: str               # 来源 B 的对立主张
    source_b_ref: str
    arbitration_guideline: str  # 综述中的中立裁决指引（分析其测试条件与口径差异）

@dataclass(frozen=True)
class ReflectionAuditReport:
    gap_findings: tuple[EvidenceGapFinding, ...]
    contradiction_findings: tuple[ContradictionFinding, ...]
    audit_passed: bool
    follow_up_queries_executed: tuple[str, ...]
```

### 3.4 综述最终报告产物 (`survey_report.py`)

```python
@dataclass(frozen=True)
class SurveyReportSection:
    chapter_id: str
    title: str
    content_markdown: str
    word_count: int
    cited_source_ids: tuple[str, ...]
    verified_claim_ids: tuple[str, ...]

@dataclass(frozen=True)
class ComprehensiveSurveyReport:
    report_id: str
    run_id: str
    objective: str
    executive_summary: tuple[str, ...]       # 核心技术要点速览
    sections: tuple[SurveyReportSection, ...]
    evolution_timeline_mermaid: str          # 编年史技术演进 Mermaid 代码
    comparison_matrix_markdown: str          # 全景对比矩阵表格 Markdown
    total_word_count: int
    total_sources_cited: int
    closed_citations: tuple[dict[str, Any], ...]
```

## 4. 阶段一拆解实施 Gates (Milestones)

阶段一划分为 4 个严谨可验证的交付 Gate：

### Gate 1.1 · 假设树与综述大纲动态生成器
- **实现范围**：
  - `src/conflux_weave/long_horizon_research/outline_planner.py`
  - 接入大模型提示工程，实现多视角课题解构，自动生成严密推导的 `ResearchOutlineTree`（5~7 章节，20+ 探针）；
  - 支持章节依赖拓扑校验（保证无环且逻辑递进）。
- **自动化测试**：
  - `tests/test_long_horizon_outline.py`：测试复发解构一致性、大纲深度、探针覆盖度与异常 Prompt 自愈修补。

### Gate 1.2 · 多源异步递归探索图与深度爬虫
- **实现范围**：
  - `src/conflux_weave/long_horizon_research/search_graph.py`
  - 调度 OpenAlex（免Key）、arXiv API、Tavily/Jina/本地 Web 抓取；
  - 建立有界并发队列（`asyncio.Semaphore`），实现 2~3 跳高质量外链递归解析；
  - 过滤黑名单、去重与权威度加权评分。
- **自动化测试**：
  - `tests/test_long_horizon_search_graph.py`：单机模拟图递归展开、深度限制（hop <= 2）、权威度过滤与速率退避。

### Gate 1.3 · 证据缝隙审计与定向补捞环
- **实现范围**：
  - `src/conflux_weave/long_horizon_research/reflection_auditor.py`
  - 自动评估大纲各章节的证据覆盖密度（Evidence Density），识别空洞探针；
  - 交叉核对不同文献声明，提炼争议项；
  - 生成二次补捞 Query 并回填素材库。
- **自动化测试**：
  - `tests/test_long_horizon_reflection.py`：验证证据稀缺捕获、冲突检测及补捞循环终止条件。

### Gate 1.4 · 分章长篇合成器与 Checkpoint 容错闭环
- **实现范围**：
  - `src/conflux_weave/long_horizon_research/survey_synthesizer.py`
  - `src/conflux_weave/long_horizon_research/workflow.py`
  - 分章节流式合成，并入已有 `step_checkpoints` 权威事务，每写完一章保存一个持久化断点；
  - 自动提炼演进谱系图（Mermaid Timeline）与对比矩阵表；
  - API 暴露与 SSE 进度推流（支持 15~20 分钟长任务的实时章节进度汇报）。
- **自动化测试与端到端回归**：
  - `tests/test_long_horizon_synthesis.py`
  - `tests/test_long_horizon_workflow_e2e.py`：断点中断重启验证、万字字数达标校验、引用封闭性检验。

## 5. 验收标准 (Acceptance Criteria)

1. **结构完备度**：产出的综述报告严格包含：执行摘要、5~7 章节深度正文、Mermaid 演进谱系图、全景横向对比矩阵表与封闭式文献引用。
2. **字数与密度**：中文正文有效字数严格落在 **8,000 ~ 15,000 字** 区间，论述透彻，杜绝模板化车轱辘话。
3. **真实多源支撑**：引用的外部参考文献与技术源数量不少于 **30 篇**，来源库采集不少于 **60 篇**。
4. **中断无损恢复**：模拟在第 3 章节合成过程中强杀进程，重启后能够读取 Checkpoint 直接进入第 4 章节合成，零重复消耗前面章节的 API Token。
5. **回归与构建**：全套自动化测试 100% 通过，Web 端 TypeScript 类型检查 0 错误。
