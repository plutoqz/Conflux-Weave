## Gate 9 · C2 Step 级 checkpoint 与恢复 ✅

- 实现：migration 11（step_checkpoints 台账：chain_phase plan…deliver、input_digest、output_artifact、attempt、status、error_ref、起止时间、resumable）+ `StepCheckpointMixin`（record/list/reuse/unknown_outcome）+ DurableResearchRuntime 集成：
  - retrieve 阶段成功后记录 checkpoint；重试时同输入摘要直接复用 EXECUTION 产物完成 attempt——不重新授权外部调用、零新增预算消耗、报告产物不变（"不从头重跑"）；
