# Conflux-Weave v0.3 W3.1 三模式对话·模式 B（知识库问答）细化实施方案

三模式回答架构第二片：本地语料检索 → 一次成文 → 片段引用（未核验聚合）。
同批交付：对话入口模式选择器改为向上弹出列表（三档全部可选）。

## 1. 模式 B 语义

- 引擎：现有 `HybridRetrievalPipeline`（BM25 + LanceDB 向量 + Rerank）检索
  Top-6 片段（每段截 1200 字符）→ 单次 LLM 成文，要求句末标注 `[n]` 片段编号，
  片段未覆盖处明确说明，禁止编造。
- 证据等级：片段级引用（chunk_id + SourceSnapshot + locator 可点溯源），
  **不做** Claim 原子化 / Verifier / 审计；UI 与来源区显式标注
  「知识库片段 · 未核验聚合」。
- 产物与存储：回答正文（含来源块）+ citations 结构化返回；
  检索命中存为轻量工件 `conflux-weave.chat-rag-context.v1`（problem、hits），
  `chat_messages` 新增 `context_artifact_id` 列（ALTER 幂等迁移）。
- 无 durable Run；LLM/Embedding/Rerank 调用照常经适配器 Artifact 存证。

## 2. 交互改动

- 模式选择器：从单选组改为**向上弹出的列表**（composer 位于页面底部）——
  按钮显示当前模式，点击弹出三档（直接问答 / 知识库问答 / 深度研究），
  每档带一句能力说明；点击外部或 Escape 关闭；追问态隐藏选择器。
- 知识库问答的回复以「知识库问答 · 未核验聚合」标签渲染，来源块随正文展示。

## 3. 装配

- `build_local_app`：检索管线构造成功则注入 `ChatService(retrieval=..., artifact_store=...)`；
  语料不可用时 `has_rag=False`，rag 请求返回 503 `corpus_not_ready`（引导改用直接问答）。
- 三模式映射：direct → ChatService.direct_answer；rag → rag_answer；
  deep → 现有 verified-research POST（W3.2 换 GPT Researcher 引擎）。

## 4. 验收（已通过）

- 单元：rag_answer 片段注入与 `[n]` 引用、citations/context 工件、
  conversation 历史携带、无语料 503；391 项测试全过。
- 浏览器：UX1 脚本经弹出列表选择深度研究，全流程不回归、零控制台错误。
- 端到端：真实语料烟测（skill 问题 → 6 条片段引用 + 带来源块的结构化回答）。
