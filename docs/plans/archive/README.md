# Archived plans

Completed or superseded plans are preserved here. Before moving a plan, record
its final status, actual validation evidence, unresolved items, and successor.

| Milestone | Final status | Successor |
|---|---|---|
| W0 | `validated_offline` | W1 minimum Research Query slice |
| W1 | bounded `validated_live` | W2 Retrieval/Evidence/Citation quality |
| W2 | bounded `validated_live` | W3 durable runtime scope freeze |

Scope-freeze files preserve the status and authorization that existed at freeze
time. Later implementation and validation results belong in the implementation
plan and acceptance records; they must not be backfilled into historical
`status_at_freeze` fields.
